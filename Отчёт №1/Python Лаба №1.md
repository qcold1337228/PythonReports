**Теоретические сведения**

Расчётная формула. Частота среза RC-фильтра определяется выражением:

f = 1 / (2 · π · R · C)

где R — сопротивление (Ом), C — ёмкость (Ф), π — математическая константа. Из формулы следует, что частота среза обратно пропорциональна произведению R·C: с ростом постоянной времени цепи τ = R·C граничная частота уменьшается.

Переменные в Python. Переменная представляет собой имя (ссылку), связанное с объектом в динамической памяти. Тип переменной определяется автоматически в момент присваивания: после преобразования float(value) имя ссылается на объект типа float. Отдельного объявления типа, как в C или Pascal, не требуется.

Модуль math. Стандартный модуль math предоставляет математические константы и функции. Константа math.pi хранит значение π с машинной точностью (15–17 значащих цифр), что превышает точность приближённого литерала 3.14159. Подключение модуля выполняется инструкцией import math.

Ввод и преобразование типов. Функция input() всегда возвращает строку (str), независимо от того, что ввёл пользователь. Для использования значения в арифметических выражениях необходима явное преобразование к числовому типу. Функция float() преобразует строку в вещественное число и принимает как обычную запись (2.5), так и экспоненциальную (1e-7). Если строка не является корректной записью числа, float() выбрасывает исключение ValueError.

Форматированный вывод. F-строка (форматированная строковая литералом с префиксом f) позволяет подставлять значения выражений непосредственно в текст.





**Код программы**

```python
  
import math


def get_float(prompt):
    value = input(prompt)
    try:
        return float(value)
    except ValueError:
        raise ValueError(f"Не число: {value!r}")


def rc_filter_frequency():
    r = get_float("Введите значение R: ")
    c = get_float("Введите значение C: ")
    return 1 / (2 * math.pi * r * c)


if __name__ == "__main__":
    try:
        f = rc_filter_frequency()
        print(f"Частота среза RC-фильтра: {f:.4f} Гц")
    except ValueError as e:
        print("Ошибка:", e)

python```
