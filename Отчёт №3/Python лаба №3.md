**Задание**

Тематика: Телеметрия испытательного стенда сервоприводов.\
Физический процесс: при испытаниях промышленного сервопривода
регистрируется временной ряд частоты вращения. Из массива необходимо
срезом выделить участок установившегося движения (исключив разгон и
торможение), очистить его от отрицательных помех и рассчитать
контрольные параметры.

Задачи модуля:

trim_transient_process(data_list, start_idx, end_idx) --- срезом
\[start_idx:end_idx\] выделяет участок установившегося режима.

calculate_channel_stats(telemetry_dict) --- принимает словарь каналов
{ch_name: \[\...\]} и вычисляет средние значения.

filter_negative_spikes(data_list) --- удаляет отрицательные выбросы из
списка замеров.

**Краткие теоретические сведения**

Модульность: Программа разбивается на отдельные файлы (модули .py). Для
подключения используется import module или from module import function.
Это позволяет переиспользовать код.

Точка входа: Конструкция if \_\_name\_\_ == \'\_\_main\_\_\': позволяет
выполнять код (например, тесты) только при прямом запуске файла, и
игнорировать его при импорте модуля в другой скрипт.

sys.argv: Список строк, содержащий аргументы командной строки.
sys.argv\[0\] --- имя скрипта, sys.argv\[1\] и далее --- переданные
параметры. Позволяет делать скрипты универсальными без правки кода.

Срезы: Синтаксис \[start:stop:step\]. Позволяет извлекать
подпоследовательности из списков. stop не включается. Срез \[::-1\]
переворачивает список.

Структуры данных: Списки (изменяемые), кортежи (неизменяемые), словари
(ключ-значение), множества (уникальные элементы).

**Код программы**

```python

def trim_transient_process(data_list, start_idx, end_idx):
    return data_list[start_idx:end_idx]


def calculate_channel_stats(telemetry_dict):
    result = {}

    for key, value in telemetry_dict.items():

        result[key] = sum(value) / len(value)

    return result


def filter_negative_spikes(data_list):
    return list(filter(lambda x: x >= 0, data_list))


if __name__ == "__main__":

    raw_rpm = [0, 450, 1495, 1502, 1498, 1500, 1505, 1100, 0]

    start_idx = 2
    end_idx = 7

    print("=== ТЕЛЕМЕТРИЯ ИСПЫТАТЕЛЬНОГО СТЕНДА ===")

    clean_data = filter_negative_spikes(raw_rpm)
    sliced_data = trim_transient_process(clean_data, start_idx, end_idx)

    stats = calculate_channel_stats({"rpm": sliced_data})

    print(f"Установившийся режим (срез[{start_idx}:{end_idx}]): {sliced_data}")
    print(f"Средняя частота установившегося режима: {stats['rpm']} об/мин")

```
