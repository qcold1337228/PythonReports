Изучение синтаксиса и практических возможностей условных операторов
(if-elif-else), циклических конструкций (while, for..in) и

**Задание**

Тематика: Таймаут пневмопривода.

Формулировка: Разработать функцию pneumatic_drive_move(t_max=5.0,
dt=0.1), моделирующую движение штока в цикле. При превышении T_max
прервать процесс по break с ошибкой «Таймаут». Функция возвращает
итоговую координату и статус.

**Краткие теоретические сведения**

Условный оператор if-elif-else используется для ветвления алгоритма по
логическим условиям. Обязательны двоеточие и отступы (4 пробела).

Цикл while выполняется, пока условие истинно. Оператор break служит для
досрочного выхода из цикла.

Пользовательские функции (def) --- многократно используемые блоки кода с
параметрами и оператором return для возврата результатов. Строки
документации (docstrings) размещаются сразу после заголовка функции.

**Код программы**

from random import randint

def pneumatic_drive_move(t_max=1.2, dt=0.1, end_pos=20):

current_time = 0

current_pos = 0

status = \"ОК\"

while True:

if current_time \> t_max:

status = \"Таймаут\"

break

if current_pos \>= end_pos:

break

current_time += dt

current_pos += randint(1, 3)

return current_pos, status
